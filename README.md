A single fortune cookie message for a crypto trader who has just been liquidated — the classic oracular line ("You will meet a tall, dark stranger") with the stranger turning out to be the stop-loss the trader never set. Rueful, warm, and short enough to read in one breath.

- **Entry:** `entry.txt` — 13 words, 73 characters
- **Program:** `main.ts` — copies `entry.txt` to `/output`
